# Maria Yepes · Portfolio

My personal site, in English and Spanish.

Built with Next.js 16, React 19, TypeScript and Tailwind CSS 4, tested with Vitest.

## Running it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000. Before pushing, `npm run check` runs formatting, lint, types and tests.

Fonts: Outfit and JetBrains Mono (SIL Open Font License).
